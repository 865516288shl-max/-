# 暖商地图

水暖、锅炉经销商查找与线索维护网页。全国省、市、区县通过高德行政区划服务加载；选中区县后继续加载可用的镇/街道选项。按选中地区、品类和关键词调用高德地点搜索，显示高德返回的电话和地址。自有线索、已拨标记及商家授权照片保存在服务端数据卷，网页定时同步共享状态。

## Cloudflare Pages 部署

Pages 项目 `nuanshang-map` 已连接本仓库的 `main` 分支；仓库采用 Pages Functions 提供 `/api/*` 接口，D1 共享线索和已拨记录，R2 保存商家授权照片。项目设置：构建命令留空，输出目录 `public`，根目录 `/`。`functions/` 位于仓库根目录，由 Pages 自动构建。向 `main` 推送提交会触发自动部署。

首次部署后在 Pages 项目设置绑定：D1 变量名 `DB`，数据库 `dealer-map-db`；R2 变量名 `PHOTOS`，存储桶 `dealer-map-photos`。运行 `migrations/0001_schema.sql` 初始化 D1。再添加运行时环境变量 `AMAP_KEY` 和 `AMAP_SECURITY_CODE`，然后重新部署。高德 Web JS Key 应限制允许域名为该 Pages 免费域名，并按高德控制台要求配置安全密钥。

## 本地运行

1. 复制 `.env.example` 为 `.env`，填写 `DOMAIN`、高德 Web JS API Key 和安全密钥。
2. 执行 `docker compose up -d --build`，然后访问 `https://DOMAIN`。

本机开发可执行 `node server.mjs`，默认访问 `http://127.0.0.1:8080`。开发模式仅绑定本机回环地址；对外访问可使用 Docker Compose 与 HTTPS。

腾讯云轻量应用服务器 Ubuntu + Docker 可用于试点部署。将域名解析到服务器公网 IP，开放 80/443 端口。中国内地节点绑定域名上线前须完成 ICP 备案；高德 Key 需将正式网址加入域名白名单，并确认商业服务许可。

## 功能与数据说明

- 地区筛选：高德 DistrictSearch 加载省、市、区县；选中区县后请求下一级镇、街道或高德提供的同级辖区。部分区县可能没有镇级结果。
- 商户搜索：按选中地区和品类调用高德 PlaceSearch；也可输入关键词。高德实时结果显示可用的电话、地址和地图点位，并可跳转高德查看原始商户照片。
- 搜索结果不写入本地线索库。高德返回可能不完整，部分商户没有电话；联系前请核实。
- 商户卡片和详情可手动设置或取消“已拨”标记。标记以本地线索编号或 POI 编号保存在服务器，供其他设备同步；点击拨号链接不会自动标记。
- 本地线索可新增、编辑、删除及 CSV 批量导入，记录电话来源、核验状态和跟进状态。
- 本站照片只展示获得权利人授权后上传的照片，保存在服务端数据卷并可删除。高德照片不由本站下载、缓存或独立展示，通过高德 POI 详情查看。
- 本网站无需登录。所有能访问网页的人都能查看、添加、修改或删除线索、照片和已拨标记；请勿录入不适合公开的资料。
- 地图 Key 由服务器提供给网页运行时，需在高德控制台限制允许的域名。

## CSV 列名

支持 `商家名称`、`品类`、`电话`、`省份`、`城市`、`区县`、`镇/街道`、`地址`、`高德POI ID`、`纬度`、`经度`、`电话来源`。至少需要商家名称。

## 运维

- `.env`、线索数据、输出目录和本地依赖目录均在 Git 忽略列表中，请勿提交凭据或客户数据。
- 线索、电话标记和照片保存在 Docker named volume `dealer_data`。部署前配置定期备份，并在备份副本上演练恢复。
- 当前版本面向单进程试点部署。扩展到多实例时应迁移到托管数据库和对象存储。
