# 镇级行政区、商家照片入口与已拨标记设计

日期：2026-11-17

## 目标与使用场景

销售人员按省、市、区县、镇/街道下钻查询水暖与锅炉商户，查看电话与本站授权照片；打过电话后可手动标红，避免团队成员重复拨打。标记需写入共享服务器数据，在其他设备刷新后仍可见。

## 范围

- 在现有省/市/区县选择器后增加镇/街道选择器。选择区县后按其高德 adcode 查询下一级行政区；具体返回项依高德数据可能显示镇、街道或同级下辖区划。搜索范围使用用户最后选中的区划。
- 增加“已拨/取消已拨”手动操作。已拨商户以红色标识，并显示标记状态；点击拨号链接不自动标记。
- 本站继续展示由商家授权上传并存储的照片；高德来源 POI 详情保留“在高德查看照片与详情”链接。本网站不抓取、缓存或独立展示高德照片。
- 本地线索及授权照片继续沿用现有共享存储和公开访问方式。

## 方案选择

1. **区划**：静态内置全国乡镇目录，或复用高德 DistrictSearch 对所选区县动态下钻。本设计选择动态查询，避免维护庞大且易过时的数据表。
2. **照片**：高德图片嵌入（需要高德明确授权及公开接口支持），或本站授权照片 + 高德详情跳转。本设计选择后者，遵守现有内容使用限制。
3. **拨打标记**：仅浏览器本地标记，或服务端共享标记。本设计选择服务端存储，按线索 ID / 高德 POI ID 区分商户，跨设备同步；支持手动撤销。

## 实现边界

- 行政区 API 未返回镇级子区划时，显示空状态/无法选择提示，不猜测或补造区划；市辖区、直辖县等层级不规则的区域按实际返回层级处理。
- 高德 PlaceSearch 的实时结果仍不保证全量，电话可能缺失；此改动不承诺高德能够提供特定 POI 的照片或电话。
- 未登录访问保持不变，因此可以访问网站的任何人均可查看、创建、编辑和删除共享数据，也能更新已拨标记。

## 验收方式

- 选择区县后镇/街道下拉项由该区县下辖数据动态填充；改变上级选项会清空并重新加载下级项。
- 选中镇/街道后商户搜索限定在该范围，并能返回页面上已有的电话和地址字段。
- 手动切换某商户“已拨”后，该商户显示红色标识；刷新页面或从另一设备访问后状态保持；可取消标记。
- 本站授权照片可在本地线索详情里查看；高德 POI 详情有跳转入口，本站不加载高德图片 URL。

## 当前实现者的默认处理

为保持最小改动，已拨状态作为独立共享标记存储，不把实时高德 POI 自动转存为销售线索；只保存 POI 标识及状态时间，不保存高德搜索详情。现有照片授权上传方式不变。
